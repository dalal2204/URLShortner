# 🔗 URL Shortener

A simple and lightweight URL shortener built with **Node.js**, **Express.js**, and **EJS** for templating.

## 🚀 Features

- Shortens long URLs to tiny links
- Generates unique short codes
- Redirects short URLs to the original long URLs
- EJS-powered front-end for basic UI
- In-memory or persistent storage (based on your setup)

## 🛠️ Built With

- [Node.js](https://nodejs.org/)
- [Express.js](https://expressjs.com/)
- [EJS](https://ejs.co/)
- [nanoid](https://github.com/ai/nanoid) (for generating short codes)
